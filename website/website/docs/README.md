# Interior Studio — security assessment documentation

This folder contains the context and scope, security requirements, security user stories and editable diagrams prepared for DFCS H4013 Application Security CA3.

## Security assessment
- [Context and scope](security/context-and-scope.md): application purpose, roles, workflows, assets, critical functions, architecture, boundaries, testing scope and preliminary observations.
- [Security requirements and user stories](security/requirements-and-user-stories.md): six testable requirements and two user stories per group member for a three-person group.

## Diagrams
- [Application architecture](diagrams/architecture.md)
- [Use cases](diagrams/use-cases.md)
- [Data flow](diagrams/data-flow.md)
- [Trust boundaries](diagrams/trust-boundaries.md)

## Using this documentation
Treat these documents as the assessment baseline and update them as the application and test coverage evolve. Record actual tester names, dates, application commit/version, tools, evidence references and outcomes in the report or test log.

The observations are preliminary source-review leads, not completed penetration-test findings. Do not mark a requirement Verified until the test has been executed against the stated application version and supported by evidence. Diagrams use Mermaid and can be edited directly in GitHub.
